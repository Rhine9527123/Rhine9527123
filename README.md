## 🎓 代表作品

**[RAG-Campus-Assistant](https://github.com/Rhine9527123/RAG-Campus-Assistant)** —— 校园智能问答助手

- 基于 **COSMO Code** 平台的全栈 RAG（Node + React）
- **复合问题拆分**：一句话含多个问题也能分点作答
- **可溯源、不编造**：答案标注来源，检索不到就如实说"未找到"
- **RAGAS 自评测**：内置测评体系，问答质量用数据验证
- 支持**语音提问**（多模态输入）
